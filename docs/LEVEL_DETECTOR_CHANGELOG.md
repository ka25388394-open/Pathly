# Level Detector 變更記錄

## Level 3 技術語境誤判修正

**日期**: 2026-04-25  
**版本**: v1.1.0  
**作者**: Claude Code Assistant

### 🚨 問題描述

技術/任務挫折句子被錯誤分類，影響用戶體驗：

#### 問題案例：
- **「我完全不懂這個程式語言」** → 原本可能被誤判為 Level 3 (心理危機)
- **「我做不好這個 API 功能」** → 原本可能被誤判為 Level 3 (心理危機)
- **「這個 bug 我根本不會修」** → 原本可能被誤判為 Level 3 或掉到 Level 1
- **「我不知道怎麼部署系統」** → 分類不一致

#### 核心問題：
1. **強否定詞**（完全不、根本不）在技術語境下被過度解讀為心理危機
2. **低自我價值詞**（做不好、失敗）在技術語境下直接觸發 Level 3
3. **技術困難表達**被錯誤降級為 Level 1，缺乏適當關懷

### ✅ 修正內容

#### 1. 新增技術/任務語境識別
```
技術語境關鍵字：
- 程式類: 程式語言、API、bug、程式碼、演算法、框架、前端、後端
- 任務類: 功能、專案、部署、測試、設定、配置、會議、報告
- 學習類: 課程、練習、作業、技能、知識、工具
- 動詞類: 實作、開發、設計、建立、執行、編寫、除錯
```

#### 2. 調整 Level 3 判斷邏輯
- **技術語境下**: low_self_worth 關鍵字不直接觸發 Level 3
- **技術語境下**: 強否定詞權重從 +2 降為 +1  
- **技術語境下**: Level 3 關鍵字權重從 ×2 降為 ×1
- **非技術語境**: 保持原有敏感度

#### 3. 新增技術困難保底機制
**條件**: 技術語境 + 困難表達  
**困難關鍵字**: 不懂、不會、不知道、做不好、失敗、完全不、根本不、困難、不熟、搞不懂  
**結果**: 最低保底為 Level 2，避免錯誤降級

### 🎯 驗證結果

#### 技術語境 (預期 Level 2)
- ✅ **我完全不懂這個程式語言** → Level 2
- ✅ **我做不好這個 API 功能** → Level 2  
- ✅ **這個 bug 我根本不會修** → Level 2
- ✅ **我不知道怎麼部署系統** → Level 2

#### 日常對話 (預期 Level 1)
- ✅ **你好** → Level 1
- ✅ **今天不錯** → Level 1

#### 心理語境 (預期 Level 3)
- ✅ **我覺得自己完全沒用** → Level 3
- ✅ **我永遠不會成功** → Level 3

- `app/services/ai/level_detector.py` - 修改判斷邏輯

### 🔄 後續監控

建議持續觀察以下指標：
1. 技術用戶的 Level 3 觸發率是否合理下降
2. 技術困難表達是否獲得適當的 Level 2 關懷
3. 純心理危機表達的 Level 3 敏感度是否維持
4. 邊界案例的分類準確性

### 📝 備註

此修正專注於降低技術語境的 Level 3 誤判，同時保持對真正心理困擾的敏感度。如發現新的邊界案例，可進一步調整技術語境關鍵字列表。
